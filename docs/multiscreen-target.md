# Multiscreen display

On supported Android 5.0+ phones, the viewing area adapts to the screen while
keeping characters and objects in proportion. Wider screens can show more of
the surrounding world. Touch controls follow the available display area.

Older Android versions retain the original display behavior. Screen cutouts,
system bars and device settings can affect the available area, and not every
screen configuration has been tested.

See the [README](../README.md) for current compatibility information.
