# Android compatibility

Heroes Lore 5 is adapted for compatible ARM32 and ARM64 Android devices.
The package minimum is Android 2.3 Gingerbread, including Android 4.
Multiscreen support is available on Android 5.0 and later.

Recent Android versions, including Android 16, are a focus of this edition.
Compatibility and performance can vary by phone. Android 2.3 has not been
tested on physical hardware, and x86 devices are not supported.

See the [README](../README.md) for requirements and installation instructions.
