# English localization

This edition includes English dialogue, menus, quests and opening captions.
Labels and dialogue layout have been adjusted for readability, with consistent
menu presentation and compact wording where space is limited.

English quest text for existing saves is improved on Android 5.0 and later.
Some artwork or older-device screens may still contain Korean text.

For downloads and current limitations, see the [README](../README.md).
Translation references are acknowledged in [CREDITS.md](../CREDITS.md).
