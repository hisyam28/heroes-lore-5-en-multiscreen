# Heroes Lore 5 v1.0.0

The first public release brings English localization and multiscreen support
to compatible Android phones. A newer edition is available from the
[latest release page](https://github.com/hisyam28/heroes-lore-5-en-multiscreen/releases/latest).

[Download APK](https://github.com/hisyam28/heroes-lore-5-en-multiscreen/releases/download/v1.0.0/heroes-lore-5-english-multiscreen-v1.0.0.apk)

## Highlights

- English dialogue, menus and quests.
- Multiscreen viewing on Android 5.0 and later.
- Fullscreen, touch-control and app-resume improvements.
- Improved English quest descriptions for existing saves on supported devices.

## Compatibility

- Package minimum: Android 2.3 Gingerbread, including Android 4.
- Compatible ARM32 and ARM64 devices; OpenGL ES 1.1 support required.
- Adapted for recent Android versions, including Android 16.
- Landscape display; multiscreen support requires Android 5.0 or later.

Compatibility varies by phone. Android 2.3 has not been tested on physical
hardware. Older versions retain the original display behavior; x86 devices
are not supported.

## Updating and known limitations

Install over a compatible previous project version **without uninstalling**
to retain saves. Some opening cutscenes may still stutter or run slowly.
Not every phone, screen or scene has been tested. Some artwork or older-device
screens may contain Korean text, and original online services are not guaranteed.
