# Title and opening presentation

The title screen uses a gold HEROES LORE wordmark with the original Roman V
and crescent emblem. COVENANT OF DARKNESS appears below the lettering with a
dark outline for readability. The edition also includes an updated launcher
icon and English opening captions.

Some opening cutscenes may still run slowly on certain phones. See the
[latest release notes](release-v1.0.5.md) for the current version and limitations.
