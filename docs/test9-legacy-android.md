# Older Android devices

The package minimum is Android 2.3 Gingerbread, including Android 4.
Older Android versions retain the original display behavior; multiscreen
support is available on Android 5.0 and later.

The stated minimum does not guarantee compatibility with every phone.
Android 2.3 has not been tested on physical hardware. See the
[README](../README.md) for the current download and requirements.
