# Installation and updates

Download the latest APK from [GitHub Releases](https://github.com/hisyam28/heroes-lore-5-en-multiscreen/releases/latest).
Allow installation from your downloader when Android requests it.

To keep existing saves, install over a compatible previous project version
without uninstalling. If installation fails, check the phone requirements and
report the device model and Android version.

See the [README](../README.md) for complete installation guidance.
