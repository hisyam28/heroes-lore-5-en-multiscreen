# Project guidelines

Keep public documentation focused on player-facing features, compatibility,
installation, known limitations and attribution.

- Preserve existing gameplay, controls and player progress when making updates.
- Check changes before describing them as complete or compatible.
- Distinguish automated checks from testing on actual phones.
- Keep personal information and credentials out of published material.
- Retain third-party acknowledgments and license notices.

See the [README](../README.md), [latest release notes](release-v1.0.5.md)
and [credits](../CREDITS.md) for public project information.
