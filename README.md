# Heroes Lore 5

**Covenant of Darkness** - English localization with multiscreen support.

**Latest release: v1.0.5**

[Download APK](https://github.com/hisyam28/heroes-lore-5-en-multiscreen/releases/download/v1.0.5/heroes-lore-5-v1.0.5.apk) | [All releases](https://github.com/hisyam28/heroes-lore-5-en-multiscreen/releases) | [Credits](CREDITS.md)

## Features

- English dialogue, menus, quests and opening captions.
- Wider viewing area on supported devices, with characters and objects kept in proportion.
- Fullscreen display and touch controls adapted for modern phones.
- Updated title artwork, a readable subtitle and a new app icon.
- Performance, save/load and app-resume improvements.
- Improved English quest text for existing saves on Android 5.0 and later.

## Compatibility

| Requirement | Details |
|---|---|
| Minimum Android | Android 2.3 Gingerbread, including Android 4 |
| Modern Android | Adapted for recent versions, including Android 16 |
| Processor | Compatible ARM32 and ARM64 devices |
| Graphics | OpenGL ES 1.1 support |
| Orientation | Landscape |
| Multiscreen | Android 5.0 and later |
| Download size | About 23 MB |

The minimum Android version is an installation requirement, not a guarantee
for every phone. Android 2.3 has not been tested on physical hardware. Older
Android versions retain the original display behavior. x86 devices are not supported.

## Installation and updates

1. Download the APK from [GitHub Releases](https://github.com/hisyam28/heroes-lore-5-en-multiscreen/releases/latest).
2. Allow installation from your browser or file manager when Android requests it.
3. To keep your saves, **install over the previous project version without uninstalling**.

Updates require a compatible previous installation. Avoid uninstalling an app
that contains saves you want to keep.

## Known limitations

- Some opening cutscenes may still stutter or run slowly on certain phones.
- Performance and compatibility vary by device; not every Android version or screen has been tested.
- Some artwork or older-device screens may still contain Korean text.
- Original online services are not guaranteed to work.
